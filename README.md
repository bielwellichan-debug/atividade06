# Atividade 06 - Tutorial de Git 💠
Nesta atividade nos foi proposto que fizéssemos um site para montar um tutorial sobre alguns comandos de Git e para que eles são utilizados!
## O que mais a atividade pedia? 🤔
Na atividade nos foi proposto também que criássemos uma biografia para o Linus Torvalds, o criador do Git!
## Por que essa atividade é interessante? 💭
Por conta que ainda temos uma certa dificuldade em lembrar os comandos de Git e qual as funções de cada um. Então, essa atividade pode nos ajudar melhor a compreender estes conceitos e caso não nos ajude muito, pelo menos vamos ter um manual sobre cada um deles!
